# MediTrack

A medication management and adherence tracking application.

## Features

- Medication scheduling
- Dose reminders
- Inventory tracking
- Refill alerts
- Adherence monitoring
- Health reports dashboard

## Tech Stack

- React
- Vite
- JavaScript
- Tailwind CSS

## Installation

npm install
npm run dev
